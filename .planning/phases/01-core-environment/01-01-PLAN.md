Cell type constants at module level:
  CELL_FREE = "."
  CELL_SHELF = "S"
  CELL_PACKING = "P"
  CELL_BLOCKED = "X"

**Grid class:**

```
__init__(self, rows: int, cols: int):
    self.rows = rows
    self.cols = cols
    self._base: dict[tuple[int, int], str] = {}   # static layout: S and P cells
    self._blocked: set[tuple[int, int]] = set()    # dynamic disruption overlay
    self._robots: dict[tuple[int, int], str] = {}  # pos -> robot label e.g. "R0"
```

Methods:
- `set_cell(self, r: int, c: int, cell_type: str) -> None` — sets _base[r,c] = cell_type. Use for placing S and P cells at reset time.
- `get_cell(self, r: int, c: int) -> str` — returns: 'X' if out-of-bounds OR in _blocked; then check _base.get((r,c), CELL_FREE). Do NOT include robots in this output (robots are overlaid in to_2d_list).
- `add_block(self, r: int, c: int) -> None` — adds (r,c) to _blocked set
- `remove_block(self, r: int, c: int) -> None` — removes (r,c) from _blocked set (no-op if not present)
- `is_passable(self, r: int, c: int) -> bool` — returns False if get_cell returns CELL_BLOCKED or CELL_SHELF; True for CELL_FREE and CELL_PACKING (robots must be able to enter packing stations to drop)
- `place_robot(self, r: int, c: int, label: str) -> None` — sets _robots[(r,c)] = label
- `remove_robot(self, r: int, c: int, label: str) -> None` — deletes _robots[(r,c)] if it equals label (no-op otherwise)
- `to_2d_list(self) -> list[list[str]]` — builds the 2D grid for Observation. For each cell: if (r,c) in _robots, cell value is the robot label; else get_cell(r,c). Returns list of rows, each row is list of cell strings.
- `reset(self) -> None` — clears _blocked and _robots (preserves _base — the static layout). Use when resetting episode.
