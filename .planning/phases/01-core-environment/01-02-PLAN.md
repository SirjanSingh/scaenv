**WarehouseEnv class** — exact signature from research Pattern 2:
```python
from openenv.core.env_server.interfaces import Environment
from warehouse_env.models import (WarehouseAction, WarehouseObservation,
                                   WarehouseState, WarehouseReward, RobotState, OrderState, RobotAction)
from warehouse_env.grid import Grid, CELL_SHELF, CELL_PACKING
from warehouse_env.tasks import TASK_REGISTRY, TaskConfig
from dataclasses import dataclass
from typing import Optional

class WarehouseEnv(Environment[WarehouseAction, WarehouseObservation, WarehouseState]):

    SUPPORTS_CONCURRENT_SESSIONS: bool = False

    def __init__(self):
        super().__init__()
        self._episode: Optional[_EpisodeState] = None
```

**reset(self, seed=None, episode_id=None, task_id: str = "solo_delivery", **kwargs) -> WarehouseObservation:**
1. If task_id not in TASK_REGISTRY: raise ValueError(f"Unknown task_id: {task_id!r}. Valid: {list(TASK_REGISTRY.keys())}")
2. cfg = TASK_REGISTRY[task_id]
3. Build grid: g = Grid(cfg.grid_rows, cfg.grid_cols); set S cells from cfg.shelf_positions; set P cells from cfg.packing_positions
4. Build robots: list of RobotState(id=i, row=pos[0], col=pos[1], carrying_item=False, assigned_order_id=None, is_active=True) for i, pos in enumerate(cfg.robot_start_positions); place each in grid as "R{i}"
5. Build orders: list of OrderState(order_id=o["order_id"], shelf_pos=tuple(o["shelf_pos"]), packing_pos=tuple(o["packing_pos"]), status="pending", created_at_step=0) for o in cfg.initial_orders
6. self._episode = _EpisodeState(task_id, step_count=0, max_steps=cfg.max_steps, grid=g, robots=robots, orders=orders)
7. return self._build_observation()

**step(self, action: WarehouseAction, **kwargs) -> WarehouseObservation:**
1. If self._episode is None or self._episode.done: raise RuntimeError("Call reset() before step()")
2. ep = self._episode
3. Build robot_actions dict: {ra.robot_id: ra for ra in action.robots}; for each robot not in dict, create RobotAction(robot_id=robot.id, action_type="wait")
4. Call self._apply_actions(ep, robot_actions) — returns WarehouseReward
5. ep.step_count += 1
6. Check done: ep.done = (all orders delivered) OR (ep.step_count >= ep.max_steps)
7. obs = self._build_observation()
8. obs.reward = reward.value
9. obs.done = ep.done
10. obs.metadata["reward_breakdown"] = reward.breakdown
11. return obs

**_apply_actions(self, ep, robot_actions: dict[int, RobotAction]) -> WarehouseReward:**
Movement resolution (GRID-03 simultaneous collision detection):
1. Compute intended_positions: dict[robot_id -> (new_r, new_c)] for each robot
   - "move_up": (r-1, c); "move_down": (r+1, c); "move_left": (r, c-1); "move_right": (r, c+1)
   - "pick", "drop", "wait" or invalid: stay at (r, c)
   - Normalize invalid action_type: if not in valid set, treat as "wait" (per D-11)
   - If target not passable: stay at (r, c)
2. Detect conflicts:
   - target_counts: dict[(r,c) -> list[robot_id]] grouping by intended position
   - For any target with 2+ robots: all those robots revert to current position
   - Swap detection: robot A wants B's current pos AND B wants A's current pos → both revert
3. Apply non-conflicting moves: remove_robot from old pos, place_robot at new pos, update robot.row/col
4. Process pick/drop actions:
   - "pick": if not robot.carrying_item AND adjacent (|dr|+|dc|<=1) to a shelf cell with a pending order assigned to this robot (or unassigned pending order): robot.carrying_item=True, order.status="picked", order.assigned_robot_id=robot.id; add +1.0 to reward breakdown "pick"
   - "drop": if robot.carrying_item AND adjacent to packing station at order's packing_pos: order.status="delivered", robot.carrying_item=False, robot.assigned_order_id=None; add +10.0 to reward breakdown "delivery"
5. Compute reward: WarehouseReward(value=sum(breakdown.values()), breakdown=breakdown)
6. Also detect collisions in intended_positions that conflicted: for each pair of robots that would have collided (same target cell), add -8.0 per pair to breakdown "collision"
7. Return WarehouseReward

**_build_observation(self) -> WarehouseObservation:**
If self._episode is None: return WarehouseObservation()
ep = self._episode
Return WarehouseObservation(
  grid=ep.grid.to_2d_list(),
  robots=list(ep.robots),
  order_queue=[o.to_dict() for o in ep.orders],
  step_count=ep.step_count,
  max_steps=ep.max_steps,

)

)


def main(host: str = "0.0.0.0", port: int = 8000):

    uvicorn.run(app, host=host, port=port)

    main()
