## Implementation Notes for Phase 2

### Pick/Drop Adjacency Logic
The current implementation uses Manhattan distance <= 1 for both pick and drop. This means a robot on the same cell as the shelf edge (distance 0) or directly adjacent (distance 1) can pick. For packing stations, the robot must be at distance <= 1 from the packing cell — since packing cells are passable, robots can also be ON the packing cell.

### Disruption Event Stubs
`TaskConfig.disruption_events` is populated for coordinated_delivery and crisis_management but the env.py does NOT consume these events. Phase 2 must add disruption processing to `step()` or a separate disruption engine. The _EpisodeState.grid._blocked set is ready to receive blocked cells from disruption events.

### Robot Breakdown
`RobotState.is_active` field exists and is checked in `_apply_actions` (inactive robots skip pick/drop processing and movement). However, the breakdown disruption event handler that sets `is_active=False` is not yet implemented — deferred to Phase 2.

### Reward Breakdown Keys
Current keys used: `"pick"` (+1.0), `"delivery"` (+10.0), `"collision"` (-8.0 per pair). Phase 2 reward keys referenced in PROJECT.md: `"fast_bonus"`, `"wasted_step"`, `"late_penalty"`, `"reroute_bonus"`, `"timeout"` — all deferred.
